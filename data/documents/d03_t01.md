# Select Appropriate Claude Product Features (Projects, Research Mode, Chat, Artifacts)

Claude is not a single box. The claude.ai product bundles several distinct working modes, and the exam tests whether you can match a business task to the right one. Choosing well saves time, keeps context organized, and produces outputs your colleagues can actually use; choosing poorly means re-pasting the same background into every conversation or letting a good draft get buried in chat scrollback.

## The four features at a glance

Think of these as answering four different questions:

- **Chat** — "I have a one-off question or a quick task." A regular conversation, no special setup.
- **Projects** — "I do the same kind of work repeatedly, over the same materials." A persistent workspace with reusable instructions and a shared knowledge base.
- **Research mode** — "I need a thorough, cited answer that pulls from many sources." An agentic mode that runs many searches and returns a structured report with inline citations.
- **Artifacts** — "I want a standalone piece of content I can see, edit, and reuse." A side-panel document, diagram, or mini-app separate from the chat text.

They are not mutually exclusive. You can produce an Artifact inside a Project, or turn on Research mode within a chat. The skill is knowing which one leads.

## Chat: the default for one-off tasks

Regular Chat is the baseline. Ask a question, draft an email, brainstorm, summarize a document you paste in. Use it when the task is self-contained and you do not expect to reuse the same context tomorrow.

Chat now carries some continuity through Memory (Claude can recall context from past standalone conversations), but Chat is still the wrong home for work that depends on a fixed set of reference documents or a consistent role and tone. When you find yourself re-pasting the same style guide or background into chat after chat, that is the signal to graduate to a Project.

## Projects: persistent context for repeated work

A Project is an organized workspace that combines two things: **custom instructions** (a standing system-level prompt that shapes every conversation in the Project — tone, role, format, constraints) and a **knowledge base** (documents, files, and text Claude can reference in every chat inside the Project). All the chats you start within a Project live together in one place.

Projects are available to Pro, Team, Max, and Enterprise users. You can upload reference material and set instructions once, then start any number of conversations that all inherit that context. On Team and Enterprise plans, Projects can be **shared** with colleagues using "Can use" or "Can edit" permissions, so a whole team works from the same instructions and source documents.

Reach for a Project when: you have a recurring workflow (weekly reports, customer-support replies, drafting against a brand voice); you have a stable set of reference documents (a style guide, a product spec, past transcripts) that should inform every answer; or several teammates need to work from the same setup. Worked example: a marketing team creates a "Brand Voice" Project holding the style guide and three sample campaigns, with instructions to always write in that voice — every new campaign chat starts already grounded.

## Research mode: thorough, cited, multi-source answers

Research mode makes Claude work **agentically**: it launches broad searches, spins up sub-agents to investigate different angles concurrently, and progressively narrows its focus, then returns a structured report with **inline numerical citations** linking to the sources it used. It trades speed for depth — answers take minutes rather than seconds — and is available on paid plans.

Use Research mode when the answer must be comprehensive and verifiable: competitive landscape scans, literature-style reviews, market or vendor comparisons, or any question where you will need to check the sources. The citations are the point — they let you verify claims rather than trust them. That matters because Claude can produce specific-looking but fabricated details; a cited report gives you links to confirm before you rely on the findings. Do not use Research mode for a quick factual lookup or a creative draft — it is slower and heavier than the task needs.

## Artifacts: standalone, editable content

An Artifact is substantial, standalone content Claude places in a dedicated side panel next to the chat — a formatted document, a table, a diagram, a chart, a slide outline, or a small interactive app. You can iterate on it directly ("make this section shorter," "change the heading"), and updates appear in the panel rather than scrolling away in the conversation. Artifacts are available on all plans, including free; some advanced capabilities (persistent storage, Live Artifacts) require a paid plan, and finished Artifacts can be published and shared via link.

Use an Artifact whenever the deliverable is a *thing* you will keep, edit, or hand off — a report, a policy draft, a project plan, a diagram — as opposed to a conversational answer. If you would otherwise copy Claude's reply out into a document, that is a sign the output should have been an Artifact.

## Matching feature to task: a decision rule

Ask, in order:

1. **Is this a reusable workflow over fixed materials, or shared with a team?** → **Project.**
2. **Does the answer need to be thorough and cited from many sources?** → **Research mode.**
3. **Is the output a standalone document/diagram I will edit or reuse?** → **Artifact.**
4. **Otherwise** → **Chat.**

## Common pitfalls the exam tests

- **Using Chat for recurring work.** Re-pasting the same brief into fresh chats is the tell-tale sign you should have made a Project. The exam rewards recognizing that persistent context belongs in a Project, not in copy-paste.
- **Over-using Research mode.** It is powerful but slow. For a quick lookup or a creative task, regular Chat is the right, cheaper choice.
- **Confusing Artifacts with Projects.** Artifacts are about *the output* (a standalone editable deliverable); Projects are about *the workspace and context* (reusable instructions plus knowledge). A common wrong answer pairs them backwards.
- **Trusting a cited report without checking.** Even in Research mode, verify high-stakes claims against the linked sources — citations enable verification, they do not replace it.
